# Дневник ДЗ

Общий школьный дневник домашних заданий для класса. Он знает расписание и сам предлагает даты ближайших уроков. Каждый входит под своим именем, пароль не нужен. Дневник запоминает вход на устройстве.

Сайт — одна страница `index.html`. Учётные записи, задания и фото хранятся в [Supabase](https://supabase.com), поэтому свой сервер не нужен. Страницу можно выложить на GitHub Pages и открывать с любого телефона.

## Настройка Supabase (один раз)

1. Открой проект в Supabase → **SQL Editor** → **New query**.
2. Вставь всё содержимое файла `supabase/schema.sql` и нажми **Run**. Файл создаст таблицы, права доступа, хранилище для фото и расписание 11б.
3. Открой **Authentication** → **Sign In / Providers** → **Email** и выключи **Confirm email**. Вход в дневнике по имени, а не по почте, поэтому подтверждать почту нечем.

Адрес проекта и публичный ключ записаны в начале скрипта в `index.html` (`SUPABASE_URL`, `SUPABASE_KEY`). Публичный ключ можно хранить в открытом коде: доступ к данным ограничен правилами в `schema.sql`.

## Публикация на GitHub Pages

В репозитории на GitHub: **Settings** → **Pages** → **Source: Deploy from a branch** → ветка `main`, папка `/ (root)` → **Save**. Через минуту сайт откроется по ссылке вида `https://<имя>.github.io/<репозиторий>/`.

## Первый вход

Первый, кто войдёт, становится администратором. Администратор может:

- задать **код класса**: без него нельзя войти под новым именем;
- импортировать данные и удалять старые задания.

Пока код класса не задан, войти может любой, у кого есть ссылка.

Вход только по имени значит, что зайти под чужим именем может любой, кто его знает. Код класса защищает только от новых людей со стороны.

## Что общее, а что своё

| Общее для класса | Своё у каждого |
|---|---|
| Расписание, кабинеты, звонки | Отметки «Выполнено» и история |
| Задания и фото к ним | План «когда делать» |
| | Тема оформления и напоминание |

## Файлы

- `index.html` — сайт целиком.
- `supabase/schema.sql` — база данных: таблицы, права доступа, функции администратора, расписание 11б.
