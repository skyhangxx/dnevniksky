# Дневник ДЗ

Общий школьный дневник домашних заданий для класса. Он знает расписание и сам предлагает даты ближайших уроков. Каждый входит под своим именем и паролем.

## Запуск

В папке проекта выполни:

```
npm start
```

Потом открой в браузере http://localhost:3000.

Сервер работает, пока открыто его окно. Чтобы остановить, закрой окно или нажми Ctrl+C.

Нужен Node.js версии 18 или новее. Сторонние пакеты не нужны.

## Первый вход

Первый, кто зарегистрируется, становится администратором. Администратор может сбрасывать пароли учеников, импортировать данные и удалять старые задания.

## С телефона

Телефон должен быть в той же Wi-Fi сети, что и компьютер с сервером. Адрес для телефона сервер пишет в своём окне при запуске. Он же есть на сайте в «Настройки → Открыть с телефона».

При первом запуске Windows может спросить, разрешить ли Node.js доступ к сети. Разреши для частных сетей, иначе телефоны не подключатся.

## Что общее, а что своё

| Общее для класса | Своё у каждого |
|---|---|
| Расписание, кабинеты, звонки | Отметки «Выполнено» и история |
| Задания и фото к ним | Тема оформления |
| | Напоминание |

## Где лежат данные

Все данные хранятся в папке `data`: учётные записи и задания в `data/db.json`, фото в `data/photos`. Пароли хранятся в зашифрованном виде.

Чтобы сделать резервную копию, скопируй папку `data`. Можно также выгрузить файл в «Настройки → Экспортировать данные».

## Файлы

- `server.js` — сервер: вход и регистрация, хранение данных, обновления в реальном времени.
- `public/index.html` — сам сайт.
